## Как проверять результат каждого этапа

После ответа Codex не переходите сразу к следующему этапу. Сначала дайте ему дополнительный запрос на самопроверку текущего изменения:

```text
Проверь только изменения последнего этапа.

1. Просмотри весь diff.
2. Найди ошибки, незавершённые заглушки и несогласованности.
3. Проверь, не были ли затронуты несвязанные части.
4. Запусти доступные тесты.
5. Исправь обнаруженные дефекты.
6. Покажи итоговый список проверок и их результаты.

Не добавляй новые функции.
```

Оптимальный цикл для каждого этапа:

```text
Основной запрос этапа
→ проверка результата вручную
→ запрос Codex на review diff
→ исправление найденного
→ переход к следующему этапу
```
